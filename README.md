# Agroforestry Carbon Finance Learning Tool

An interactive educational tool designed to explain how agroforestry carbon finance works through progressively layered modules.

The project focuses on intuition first learning rather than detailed carbon accounting or investment modeling. The goal is to help users understand how biology, timing, financing, pricing, rollout pacing, and benefit sharing interact within agroforestry carbon projects.

## Current structure

### Module 1A: Project economics
Introduces simplified project economics using:
- carbon price
- project duration

Additional stages introduce:
- funding gaps
- verification/payment delay
- financing cost

### Module 2: Carbon generation and pricing
Explores:
- biological growth curves
- verification timing
- contracted vs. spot pricing dynamics

### Module 3: Cost structure and rollout pacing
Explores how implementation speed changes the timing of project costs.

### Module 4: Financing and investor attractiveness
Explores:
- concessional financing
- investor return thresholds
- grant support required to reach target IRRs

### Module 5: Benefit sharing
Explores tradeoffs between:
- farmer payments
- project sustainability
- investor returns

### Module 6: Integrated system view
Provides a simplified scorecard summarizing:
- climate impact
- farmer benefit
- investor attractiveness
- subsidy dependence

## Excel workbook

The repository also includes a simplified Excel workbook showing:
- cash-flow mechanics
- IRR calculations
- grant support mechanics
- farmer-share sensitivity

The workbook is intended as a lightweight educational companion rather than a full replication of the website.

## Deploy to GitHub Pages

1. Upload `index.html`, `README.md`, and the Excel workbook to the repository root.
2. Go to **Settings → Pages**
3. Set Source to `Deploy from a branch`
4. Set Branch to `main`
5. Save
