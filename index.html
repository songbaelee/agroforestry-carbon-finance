Why do biological assumptions change the carbon curve so much?

This view compares simplified biological growth patterns across agroforestry archetypes. The curves are normalized for educational purposes rather than tied to exact hectares, tons, or issued credits. The core intuition is simple: trees grow slowly, and timing matters.

Module 2A lesson

Carbon forecasts are biological forecasts first.

Before a project can sell carbon credits, it needs trees to survive, grow, and accumulate carbon over time.

The same project size can produce very different carbon curves depending on rainfall, growth speed, survival, and system type.

Design choice: one simple rainfall/water control changes curve shape. It is not a carbon accounting input yet.

About this tool

This project began as an attempt to explain agroforestry carbon finance in a simpler and more visual way. Carbon finance models can become extremely complicated very quickly, especially when discussing biological growth, verification timing, financing structures, and revenue sharing.

Stage 1A intentionally keeps the model simple by focusing on two core variables: carbon price and project length. Most biological and operating assumptions are held constant for now.

The goal is educational rather than predictive. This is not a full project finance model and should not be used for investment decisions.

The tool was built iteratively using ChatGPT, Chart.js, GitHub Pages, and a downloadable Excel companion model.

Related tools and further exploration

Most tools are either climate-first or finance-first. This project aims to sit between the two: a simple translation layer for understanding how agroforestry carbon project design, timing, revenue, and financing interact.

How this tool is different

Most existing tools focus on carbon accounting, emissions footprints, forest carbon estimation, or detailed financial modeling. This project is different. It is designed as an intuition-first learning system to help users understand the basic economics of agroforestry carbon finance before moving into more technical tools.
